# 薅羊毛

优惠线报、免费试用、云电脑与 AI 免费额度，一处汇总的静态工具站。

## 功能

- **线报**：汇总各平台优惠线报，支持按平台筛选（京东 / 淘宝 / 拼多多 / 抖音 / 美团 / 银行App / 云资源 / 其他）、按类型筛选（红包 / 优惠券 / 服务器 / 云电脑 / AI额度 / 其他）、关键词搜索、收藏。线报卡片显示来源域名和抓取日期。
- **我的资源**：登记已领取的云电脑、服务器、AI 额度等资源，字段包括名称、链接、类型、注册方式、领取日期、到期日期、备注；支持添加、编辑、删除，到期资源会标红提示；可指定归属账号。
- **账号绑定**（可选，需要本地后端）：绑定京东、淘宝平台账号（扫码登录或短信登录），绑定后线报和资源可以挂到指定账号下面。绑定前需要明确勾选同意。
- **每日签到**：记录各平台 App 的每日签到任务，支持添加、删除、打卡与取消打卡，连续天数自动累计。

## 使用

### 直接打开

双击 `index.html` 即可在浏览器中使用。注意：通过 `file://` 直接打开时，浏览器安全策略可能阻止加载内置的 `data/deals.json`，此时线报列表为空，点击「导入线报 JSON」选择 `data/deals.json` 即可正常使用。

### 本地服务器（推荐）

```bash
cd hao-yang-mao
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

### 本地后端（账号绑定需要）

账号绑定需要启动 `server/` 下的本地后端（只用 Node 内置模块，无任何依赖）：

```bash
cd hao-yang-mao/server
node server.js
```

默认只监听本机 `127.0.0.1:3000`，打开 `http://127.0.0.1:3000` 使用。端口可用环境变量覆盖：`PORT=3001 node server.js`。

### 部署到 GitHub Pages

1. 将本仓库推送到 GitHub。
2. 打开仓库 Settings → Pages，Source 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存。
3. 稍等片刻后，通过 `https://<用户名>.github.io/hao-yang-mao/` 访问。

注意：GitHub Pages 是纯静态托管，没有后端，账号绑定功能在上面不可用；需要绑定账号时请在本地启动后端使用。

## 账号绑定

### 绑定流程

1. 打开「账号绑定」页，先勾选同意（绑定前必须明确同意）。
2. 选择平台（京东、淘宝）和方式（扫码登录或短信登录）。
3. 扫码：页面展示二维码，用对应平台 App 扫码并确认；短信：输入手机号获取验证码，再输入验证码校验。
4. 成功后，账号出现在「已绑定账号」列表，可在「我的资源」和线报卡片上指定归属账号；线报页也可以按账号筛选。

### 同意与安全

- 绑定前必须勾选同意，未勾选时无法发起绑定；解绑时立即清除本机保存的该账号会话。
- 登录会话只保存在本机浏览器（localStorage），不上传到任何服务器；后端是无状态中转，只把登录请求转发到平台自己的登录接口。登录尝试的临时状态（二维码 token、临时 cookie）只存在后端内存里，5 分钟过期自动清除，永不写盘；手机号、验证码、会话内容不在服务端留存，也不记入日志（日志里手机号只显示脱敏形式）。
- 账号列表只显示平台、脱敏后的账号标识（如手机号中间打码）、绑定方式和绑定时间。
- 清除浏览器数据后，本机保存的会话和账号记录会一并丢失，需要重新绑定。

### 限制（请先了解）

- 登录成功不等于能自动拉取个人券：券的自动同步依赖各平台页面结构，本次不做，留待后续版本；目前绑定后可以手动把线报和资源归属到指定账号下面。
- 京东短信登录：平台侧有图形验证和加密握手等反机器人校验，校验不通过时接口会原样返回平台的提示；遇到这种情况请改用扫码登录。
- 淘宝短信登录：淘宝网页短信登录没有可直接调用的公开接口，请使用扫码登录。
- 京东扫码票据校验目前使用历史项目里一直沿用的明文形式；如果平台侧收紧，校验失败时接口会如实返回平台提示，需要在京东登录页重新扫码。
- 平台接口可能随网页改版变化，遇到整体失效时以平台实际页面为准。
- 获取二维码或轮询扫码状态时如果遇到网络波动导致失败，页面会提示失败原因，点「重新获取」重试即可；轮询遇到短暂网络波动时会自动继续等待，不会中断扫码。

## 数据说明

- **线报数据**：内置样例位于 `data/deals.json`，字段为 `title`、`url`、`platform`、`deal_type`、`summary`、`source_domain`、`fetched_date`。每日刷新目前是手动更新：把新的线报整理成同样格式的 JSON，替换 `data/deals.json` 后重新部署，或在页面上点击「导入线报 JSON」直接导入（导入的数据保存在本机浏览器）。
- **个人数据**：收藏、我的资源、签到任务、已绑定账号及其会话、线报归属关系只保存在本机浏览器的 `localStorage` 中，不上传到任何服务器。换浏览器或清除浏览器数据后，这些记录会丢失。
