# 薅羊毛

优惠线报、免费试用、云电脑与 AI 免费额度，一处汇总的静态工具站。

## 功能

- **线报**：汇总各平台优惠线报，支持按平台筛选（京东 / 淘宝 / 拼多多 / 抖音 / 美团 / 银行App / 云资源 / 其他）、按类型筛选（红包 / 优惠券 / 服务器 / 云电脑 / AI额度 / 其他）、关键词搜索、收藏。线报卡片显示来源域名和抓取日期。
- **我的券**：免登录收券。把各平台 App 里的券链接粘贴进来，工具从链接域名自动识别平台，按平台和账号标签归类；到期前提醒，点链接去领。不需要登录，不用后端。
- **我的资源**：登记已领取的云电脑、服务器、AI 额度等资源，字段包括名称、链接、类型、注册方式、领取日期、到期日期、备注；支持添加、编辑、删除，到期资源会标红提示。
- **每日签到**：记录各平台 App 的每日签到任务，支持添加、删除、打卡与取消打卡，连续天数自动累计。

## 使用

### 直接打开

双击 `index.html` 即可在浏览器中使用。注意：通过 `file://` 直接打开时，浏览器安全策略可能阻止加载内置的 `data/deals.json`，此时线报列表为空，点击「导入线报 JSON」选择 `data/deals.json` 即可正常使用。

### 本地服务器（推荐）

```bash
cd hao-yang-mao
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

### 部署到 GitHub Pages

1. 将本仓库推送到 GitHub。
2. 打开仓库 Settings → Pages，Source 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存。
3. 稍等片刻后，通过 `https://<用户名>.github.io/hao-yang-mao/` 访问。

本项目是纯静态站，没有后端，所有功能（包括收券）在 GitHub Pages 上直接可用。

## 收券

### 收券流程

1. 打开「我的券」页，在券链接框粘贴券链接（必填）。
2. 粘贴后页面自动从链接域名识别平台（京东、淘宝、拼多多、抖音、美团、银行App）；识别结果显示在链接框下方。
3. 填写标题、面额、到期日期、账号标签（全部可选）。账号标签是自由文本，例如「主号」「小号」，用来区分多个账号下的券，不登录、不验证。
4. 点「收券」，券出现在列表里，按平台和账号标签归类。

### 券列表

- 按平台筛选、按账号标签筛选、按状态筛选（未使用 / 已使用 / 已过期）、关键词搜索。
- 到期日在 3 天内的券标「即将到期」并高亮显示；已过期的券置灰并标注已过期。
- 点「去领」在新窗口打开原链接，自行领取；点「标记已使用」改状态；点「删除」移除。

### 限制（请先了解）

- 平台是从券链接的域名识别的：jd.com、jd.hk、u.jd.com 识别为京东；taobao.com、tmall.com、tb.cn 识别为淘宝；含 pinduoduo、douyin、meituan 的域名识别为对应平台；链接里含银行关键词的识别为银行App。
- 短链、跳转链接、通用短域名（如 t.cn、bit.ly）从域名看不出是哪个平台，识别不出来时会归入「其他」；遇到这种情况请在收券表单里手动选择平台。
- 券的标题、面额、到期日由填写的内容决定，工具不从平台页面读取，领之前请以平台实际页面为准。

## 数据说明

- **线报数据**：内置样例位于 `data/deals.json`，字段为 `title`、`url`、`platform`、`deal_type`、`summary`、`source_domain`、`fetched_date`。每日刷新目前是手动更新：把新的线报整理成同样格式的 JSON，替换 `data/deals.json` 后重新部署，或在页面上点击「导入线报 JSON」直接导入（导入的数据保存在本机浏览器）。
- **个人数据**：收藏、我的券、我的资源、签到任务只保存在本机浏览器的 `localStorage` 中，不上传到任何服务器。换浏览器或清除浏览器数据后，这些记录会丢失。

## 线报来源与免责

线报来自公开渠道，内容未经核实，活动有时效性，以平台实际页面为准。领取前请自行甄别，谨防受骗；涉及付费、绑卡、实名验证的活动请谨慎参与。
