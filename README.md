# 薅羊毛

优惠线报、免费试用、云电脑与 AI 免费额度，一处汇总的静态工具站。

## 功能

- **线报**：汇总各平台优惠线报，支持按平台筛选（京东 / 淘宝 / 拼多多 / 抖音 / 美团 / 银行App / 云资源 / 其他）、按类型筛选（红包 / 优惠券 / 服务器 / 云电脑 / AI额度 / 其他）、关键词搜索、收藏。线报卡片显示来源域名和抓取日期。
- **我的资源**：登记已领取的云电脑、服务器、AI 额度等资源，字段包括名称、链接、类型、注册方式、领取日期、到期日期、备注；支持添加、编辑、删除，到期资源会标红提示。
- **每日签到**：记录各平台 App 的每日签到任务，支持添加、删除、打卡与取消打卡，连续天数自动累计。

## 使用

### 直接打开

双击 `index.html` 即可在浏览器中使用。注意：通过 `file://` 直接打开时，浏览器安全策略可能阻止加载内置的 `data/deals.json`，此时线报列表为空，点击「导入线报 JSON」选择 `data/deals.json` 即可正常使用。

### 本地服务器（推荐）

```bash
cd hao-yang-mao
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

### 部署到 GitHub Pages

1. 将本仓库推送到 GitHub。
2. 打开仓库 Settings → Pages，Source 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存。
3. 稍等片刻后，通过 `https://<用户名>.github.io/hao-yang-mao/` 访问。

## 数据说明

- **线报数据**：内置样例位于 `data/deals.json`，字段为 `title`、`url`、`platform`、`deal_type`、`summary`、`source_domain`、`fetched_date`。每日刷新目前是手动更新：把新的线报整理成同样格式的 JSON，替换 `data/deals.json` 后重新部署，或在页面上点击「导入线报 JSON」直接导入（导入的数据保存在本机浏览器）。
- **个人数据**：收藏、我的资源、签到任务只保存在本机浏览器的 `localStorage` 中，不上传到任何服务器。换浏览器或清除浏览器数据后，这些记录会丢失。
